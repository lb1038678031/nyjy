# 纳福剪影 (Nafu Jianying)

**纳福剪影** 是一款基于 AI 的中国传统剪纸艺术生成网页应用。用户只需输入创意灵感，即可生成具有浓郁中国年味的剪纸作品。

## 🌟 特色功能
- **AI 赋能**：采用先进的图像生成模型（如 FLUX.1），精准还原剪纸艺术精髓。
- **多种风格**：提供传统窗花、生肖瑞兽、纳福文字等多种预设剪纸风格。
- **纯前端实现**：无需后端，API Key 本地存储，安全可靠。
- **历史集锦**：自动记录您的创作历程，支持随时查看与再次下载。
- **年味视觉**：深度定制的中国红与金色视觉主题。

## 🛠️ 技术栈
- **框架**：Vue 3 (Composition API) + TypeScript
- **构建**：Vite
- **UI 组件**：Element Plus
- **样式**：Tailwind CSS
- **图标**：Lucide Vue Next
- **API**：SiliconFlow (OpenAI 兼容)

## 🚀 部署建议

由于本项目为纯静态前端应用，您可以将其部署在支持静态网站托管的平台上。针对**国内访问环境**，以下是推荐的免费托管方案：

### 1. Gitee Pages (最推荐 - 国内原生)
- **优势**：国内服务器，访问速度极快，无需担心网络波动。
- **操作**：直接在 Gitee 仓库的“服务”菜单中开启。

### 2. 21云盒子 (21YunBox - 国内版 Vercel)
- **优势**：专门为国内开发者优化的自动化部署平台，支持从 GitHub/Gitee 导入，国内访问有节点加速。
- **操作**：注册账号后关联 Gitee 仓库，选择 Vite 模板即可一键部署。

### 3. Coding Pages (腾讯云旗下)
- **优势**：依托腾讯云基础设施，稳定且国内访问顺滑。
- **操作**：在 Coding 项目管理中开启“静态网站”功能。

### 4. Vercel / Cloudflare Pages (国际主流 - 速度较快)
- **优势**：自动化程度极高。虽然服务器在境外，但由于使用了 Anycast 网络技术，国内大部分地区访问速度尚可。
- **注意**：其默认域名（如 `.vercel.app`）在部分地区可能存在访问不稳定的情况，建议绑定自定义域名。

## 📦 部署指南 (以 Gitee Pages 为例)

1. **准备仓库**：在 Gitee 上创建一个新仓库（如 `nfjy`）。
2. **构建项目**：
   ```bash
   npm run build
   ```
3. **推送代码**：将构建生成的 `dist` 目录下的内容推送到仓库的 `master` 分支（或创建一个 `gh-pages` 分支）。
   > **注意**：如果您部署在非根目录下（例如 `https://gitee.com/yourname/nfjy/`），请确保 `vite.config.ts` 中的 `base` 已正确配置。当前项目默认已配置为 `base: './'`，可兼容大多数部署环境。
4. **开启服务**：
   - 进入 Gitee 仓库页面，点击顶部菜单的 **服务** -> **Gitee Pages**。
   - 选择部署分支（通常是 `master`），点击 **启动**。
   - 等待部署完成后，即可通过生成的 URL 访问您的“纳福剪影”。

## 🔑 API 配置
本应用需要配置 SiliconFlow 的 API Key 才能正常工作：
1. 前往 [SiliconFlow 官网](https://cloud.siliconflow.cn/) 注册并获取 API Key。
2. 在应用右上角的“设置”中输入您的 API Key 并保存。
3. 输入您的创意，点击“唤醒剪纸之魂”开始创作！
